# Match Tracker — Application Web CRUD Conteneurisée

Application de gestion de matchs et tournois composée d'un frontend React (Vite + Nginx), d'une API REST Node.js / Express et d'une base de données PostgreSQL, orchestrés avec Docker Compose.

## Démarrage rapide

1. Copier le fichier d'environnement :
   cp .env.example .env

2. Lancer l'application :
   docker compose up -d --build

3. Ouvrir http://localhost:8088 dans le navigateur.
